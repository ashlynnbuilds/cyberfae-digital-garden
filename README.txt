CYBERFAE v0.3 MVP TEST BUILD

1. BACK UP your existing cyberfae-terminal folder before replacing anything.
2. Copy index.html, garden.js, main.js, package.json, and assets into your project.
3. Open a PowerShell terminal inside the project.
4. Run: npm install
5. Run: npm start
6. Test 15 completions, plant growth, restart persistence, clear completed, and new garden confirmation.
7. For a Windows portable EXE, run: npm run dist
8. Find the EXE inside dist. Test it on your own computer before sharing.

NOTE: This archive is source code, NOT a tested Windows executable. Existing saved progress should be preserved if run from the same Electron app origin/user data directory; make a backup first. Reset garden deletes progress only after confirmation. The project uses the same v2 storage key.
